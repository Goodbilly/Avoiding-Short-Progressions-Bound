# Avoiding-Short-Progessions-Bound
We say that \(\mathbb{E}^n\not\ell_3,\alpha\ell_M\) if there is a coloring of points in \(\mathbb{R}^n\) using red and blue so that there are no 3 collinear red points with consecutive points of distance one apart and no M collinear red points with consecutive points of distance \alpha>0 apart.
